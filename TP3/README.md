# Creación de una MT para un lenguaje regular y una MT para un lenguaje independiente del contexto. Crear un Cuadro comparativo entre una MT aceptable vs una MT calculable.

### Comparación de Máquinas de Turing

| Característica | MT Aceptable | MT Calculable |
| :--- | :--- | :--- |
| **Propósito** | Clasificar, determinar si una cadena pertenece a un lenguaje formal. | Procesar, calcular una función o transformar una entrada. |
| **Salida** | Aceptación o rechazo. | Una cinta con datos. |
| **Uso de la cinta** | Temporal, sirve para recorrer los distintos símbolos de la entrada. | Principal, el contenido final que se encuentre en la cinta es la respuesta. |
| **Condición** | Detenerse en un estado de aceptación. | Detenerse en un estado final, con el contenido esperado escrito en la cinta. |
